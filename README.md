# Marvel: Code of Heroes

A cinematic Marvel-inspired event website created for the
GeeksForGeeks Student Chapter, Bennett University.

## Live Website

https://marvel-code-of-heroes-copy-6f51e3aa.base44.app/

## Concept

"Marvel: Code of Heroes" combines the cinematic visual language of
superhero storytelling with the technical culture of GeeksForGeeks.

The website uses large-scale visuals, cinematic transitions,
interactive hero selection, dynamic color themes, animations,
event information, countdown elements, and a registration CTA.

## Features

- Cinematic hero section
- Marvel-inspired character themes
- Interactive hero selection
- Animated transitions
- Responsive design
- Event information section
- Countdown timer
- Timeline
- Registration CTA

## Technologies

- React
- JavaScript / TypeScript
- CSS
- Base44
- Responsive Web Design
